# 2026-11-16 대화 동기화 출처와 범위

이 문서는 현재 대화에서 직접 확인 가능한 사용자 발언과 assistant 논의를 보존하는 기록이다. 아래 사용자 블록은 문구를 그대로 옮겼으며 줄바꿈은 문서용으로 정리했다. 다른 세션의 모든 메시지를 export한 것이 아니다. 동기화 날짜와 이전 메시지의 작성 날짜는 동일하다고 가정하지 않는다.

## 사용자 원문: CRUD와 공동논문 목적

```text
Continual learning의 목적은
- 무한한 시간동안 경험하는것을 재앙적 망각 없이 학습 하는 것

이때 생각해야 하는 point를 CRUD에 빗대에
1. 간섭없이 새로운 지식을 학습 -> Update
2. 무한히 증가하는 지식에 대해서 망각의 비용을 어떻게 치뤄야할지 -> Delete
3. 현재 입력된 문맥에 활용할 지식을 어떻게 잘 가져올지 -> Read

3가지 포인트가 있다고 봄. 우리의 솔루션기준으로는
1. Schemal based learning의 조절을 적용. 그래서 기존 지식(low rank expert)에 대한 in place update를 진행함. 그리고 문맥에 따라 적합한 schema를 못찾으면 create로 진행해서 새로운 low rank expert를 생성함
2,3에 대해서는 이런것처럼 우리 솔루션에서 어떻게 해결한다고 할 수 있을지 1,2,3에 대해서 다시 얘기해봐

이걸 하는 목적은 이제 ali에게 joint paper에 대한 상세한 내용을 제안할거라서 그걸 위해서 어떤 내용을 어떤 흐름으로 얘기할지 만들어야해서 그럼
```

대응 문서: [CRUD·공동논문 연구안](../../docs/14-schema-lifecycle-crud-and-joint-paper.md). 사용자 원문의 'Schemal'은 여기서 보존했고 설계문서는 schema-based learning으로 표기했다. Assistant가 제안한 상세 정책과 수치는 별도 PROPOSAL이며 사용자 확정사항으로 승격하지 않는다. 공동논문 제안은 미발송이다.

## 사용자 원문: 지속 동기화

```text
full continual learning repo에 대화내용과 정보를 항상 update해둬
```

대응 문서: [SYNC_POLICY](../../SYNC_POLICY.md). 프로젝트 관련 접근 가능한 대화와 보고의 변경분을 지속 반영하되, 전체 계정의 모든 대화에 대한 실시간 접근을 보장하지 않는다.

## 최근 assistant 내용의 이관

- [11/16 SBL 보고](../../research/2026-11-16-sbl-tracking.md): 원 보고의 중심 주장, 수치, 한계, 링크, 다음 추적 항목을 재구성했다. 논문 본문을 이번에 다시 읽은 것이 아니다.
- [영향·AGI 가설 기록](../../research/2026-11-16-impact-hypotheses.md): '강한 형태를 입증한다면'이라는 조건부 평가다. 실제 성과·수상·기업 반응이 아니다.
- Schema 정의·분해·간섭과 수학적 조건은 기존 [13번 문서](../../docs/13-schema-decomposition-and-interference.md)에 이미 반영되어 있어 덮어쓰거나 중복 생성하지 않는다.

## 보존 중 확인한 정정 필요

11/16 보고는 Tian의 영장류 schema 연구를 처음 발견한 것으로 표현했지만, 현재 대화의 이전 SBL 개괄 답변에도 이미 소개가 있다. 원 보고의 출처는 유지하면서 신규성 표시를 확정하지 않는다. 이는 대화 간 중복 판정이며 논문의 내용·날짜를 새로 검증한 작업은 아니다.

**처리 (2026-11-17 검토):** 저장소 안에서 확인되는 사실로 판정한다. Tian et al.은 [catalog.tsv](../../references/catalog.tsv) N28(Tian et al.; 2026-01-29, official-search-checked)과 [2026-11-02-baseline.md](../../research/2026-11-02-baseline.md) 33행에 첫 커밋(2026-11-09)부터 있고 [03-foundations.md](../../docs/03-foundations.md) §4가 [N25–N30]으로 인용한다. 2026-11-09 주간 기록과 2026-11-11 원문 검토 11편에는 이 논문이 없다. 따라서 11/16 보고의 '신규 발견' 표시는 저장소 기준으로 신규가 아니며 기존 N28의 재검토·상세화로 분류하고 주간 신규 발견 수에 넣지 않는다. 서지만 DOI 레지스트리(Crossref)로 대조했다. Nature Communications 17, 2150, 2026-01-29, 저자 8명이며 보고와 일치한다. 이전 bioRxiv 2024-10-27, 원문 수치, 분석 코드는 확인하지 못해 보고 이관으로 남긴다.

## 이번 작업의 경계

대상 HEAD를 읽고 기존 지침을 확인했다. 문서와 동기화 정책만 추가하며 코드·학습·배포·외부 메시지 발송은 수행하지 않는다. 원 논문의 전문 및 무관한 개인 자료를 게시하지 않는다. 부분 원문과 재구성 요약을 전체 문자 단위 원문이라고 표현하지 않는다.

로컬 git clone은 실행 환경의 DNS 문제로 실패했으므로 저장소 전체를 대상으로 한 validator 실행을 주장하지 않는다. GitHub connector를 통한 파일·tree·commit의 확인과 변경 범위 검사를 사용한다. 모델 효용 실험은 0회다.
