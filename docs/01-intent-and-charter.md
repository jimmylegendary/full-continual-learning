# 01. 연구 헌장: 경험이 이해·사고·학습 방식을 바꾸는 모델

상태: **사용자 의도와 연구 방향의 정리**. 실제 아키텍처나 성능이 확정된 명세는 아니다. 최종 통합 방향은 초기의 외부 메모리·별도 판단기 제안보다 우선한다.

## 1. 한 문장 정의

> 경험에서 재사용 가능한 연속적인 schema를 형성하고, 그 schema가 현재 입력의 해석과 계산 경로, 필요한 학습을 제어하며, 깊은 사고의 성과가 미래의 빠른 판단으로 전환되는 하나의 System ONE.

현재 계보는 Melete → 경험 기반 조건부 판단 → schema-based learning → pretrained LLM retrofit → recurrent System ONE → 상태·내용 의존적 학습 조율이다. 명칭 변경이 이전 목적의 폐기를 의미하지 않는다.

**USER (B16, 2026-10-13):** Melete의 진짜 목표는 Experience → Latent Conditional Judgment → Revisable Decision이며 결과 예측이 아니다. 통합 모델에서도 이 목표를 유지한다. 경험이 만든 잠재 조건부 구조가 현재 입력에 대한 판단을 정하고, 새 근거가 오면 그 판단을 고칠 수 있어야 한다.

**ARCHIVE:** 이전 N0/N1 prototype은 8개 cue에서 3채널의 후속 결과를 예측하는 과제였고, 이것이 암묵적 조건부 판단을 측정한다는 연결은 검증되지 않았다고 사후 검토에서 정리됐다. 교정은 조건별 선택·미관측 조합·반례·복귀를 주 endpoint로 정의하는 것이었다 ([2026-10-15-neural-review-postmortem.md](https://github.com/jimmylegendary/melete/blob/1d95136c3a64580ec25bc588c96c191eecb85b41/docs/implementation/records/2026-10-15-neural-review-postmortem.md)).

**PROPOSAL:** FCL의 주 판단 지표는 조건별 선택(보류 포함)의 정답·보호·복귀다. 결과값 예측 오차(MSE 등)는 보조 지표이며 조건부 판단의 성공으로 대체하지 않는다. 평가 설계는 [08-evaluation.md](/home/jimmy/repos/full-continual-learning/docs/08-evaluation.md)를 따른다.

## 3. 여섯 층위의 의도

1–3층은 명시적 요구의 재구성, 4–6층은 대화에서 도출한 해석이다. 사람의 내면을 확정 진단한 것이 아니다.

### 1층: 구현 재료

Looping은 반복 연산, MoD/MoR은 계산 배분, depth attention은 중간 표현 재사용, Titans/HOPE/CMS는 내부 기억과 변경, 뇌 리듬은 시간적 조율의 후보 원리를 제공한다. 단지 관련 논문을 나열하는 것이 아니라 계산 그래프와 상태·학습 규칙으로 연결한다.

### 2층: 경험에 따라 달라지는 행동

익숙한 관계는 짧게 처리하고 새 binding은 적은 관측으로 학습한다. 구조를 조합해야 하거나 해석이 맞지 않으면 더 깊게 계산한다. 중요한 것은 입력뿐 아니라 **이전에 어떤 경험을 했는지에 따라 처리 방식이 달라지는 것**이다.

### 3층: 사고 중에도 이해의 틀을 재선택

초기에 schema를 한 번 선택하고 끝내지 않는다. 반복 중 발견한 불일치로 기존 해석 유지, 적용 조건 수정, 다른 schema 전환, 여러 schema 조합, 새 구조 형성 중 무엇이 필요한지 다시 판단한다. 같은 모델의 숙고와 학습이 서로 영향을 준다.

### 4층: 경험은 유용한 편향을 만든다

무엇을 먼저 확인하고, 어떤 근거를 받아들이고, 어떤 해석부터 시도하며, 어떤 계산을 생략하는지가 경험으로 형성된다. Artificial Biased Intelligence의 편향은 오류를 고집하는 성향이 아니라 조건부 prior다. 관련 반례가 오면 바뀔 수 있어야 한다.

**USER (B04, 2026-10-05):** 관심·수준·편향은 모델이 경험으로 형성한 자체 상태다. 외부에서 주어진 사용자 프로필이나 고정 규칙이 아니다.

**PROPOSAL:** 모델 상태에 '관심'(무엇을 더 배우려 하는가)과 '수준'(현재 어디까지 이해하는가)을 편향·정책과 같은 층위의 학습 상태로 둔다. 둘은 읽기·쓰기·계산 깊이를 정하는 신호이며, 초기 seed 값은 manifest에 명시하고 경험으로 형성된 효과와 따로 평가한다. 정의와 측정은 [04-rhythms-and-orchestration.md](/home/jimmy/repos/full-continual-learning/docs/04-rhythms-and-orchestration.md)의 학습 가능성 항을 따른다.

**ARCHIVE:** Melete도 관심·편향·수준을 자체 경험으로 형성된 상태로 두고 familiarity·관심·학습 가능성·surprise를 하나의 임계값으로 합치지 않는다고 정리했다 ([2026-10-15-neural-judgment-roadmap.md](https://github.com/jimmylegendary/melete/blob/1d95136c3a64580ec25bc588c96c191eecb85b41/docs/superpowers/plans/2026-10-15-neural-judgment-roadmap.md)).

**OPEN:** 관심·수준이 하나의 벡터인지 문맥별 다차원(방향성)인지는 정하지 않았다.

### 5층: 학습과 사고의 정책도 학습

무엇을 기억할지, 얼마나 생각할지, 언제 기존 이해를 보호할지, 어느 차원을 확장할지까지 경험과 평가로 개선한다. 온라인 state 학습, Sleep/consolidation, 코드를 개선하는 development evolution은 서로 다른 시간척도와 권한을 가진다.

### 6층: 지능은 경험에 따른 자기 조직화

과거 경험이 현재의 이해 방식을 만들고, 현재의 사고가 새 경험을 해석하며, 결과가 다시 미래의 이해를 바꾼다는 관점이다. 같은 초기 모델이라도 이력에 따라 잘 알아보는 구조, 우선 가설, 계산량, 학습 정책이 달라질 수 있다는 연구 가설이다.

## 4. 두 개의 중심 명제

**H-SAMPLE:** 관련 경험에서 배운 구조가 새로운 대상·표현을 가진 과제에 대한 목표 성능까지의 관측 수를 줄인다.

**H-COMPUTE:** 경험과 통합 이후 새로운 구조 공유 사례에서 같은 정확도를 얻는 데 필요한 총 계산이 줄어든다. loop만 줄이고 gradient·검색·decoder 비용을 늘린 결과를 계산 개선으로 인정하지 않는다.

두 명제는 독립적으로 평가한다. Rapid learning이 빨라져도 추론이 느릴 수 있고, early exit가 좋아져도 지속학습이 없을 수 있다.

## 5. 비목표와 금지된 축소

- 일반 RAG, 개인 선호 요약, DB/JSON schema 검색만으로 목표 완료 처리하지 않는다.
- 외부 frozen LLM의 프롬프트 앞에 원문을 붙이는 성공을 최종 neural schema 시스템으로 바꾸지 않는다. 다만 강한 대조군으로 유지한다.
- LLM에 구조적 표상이 전혀 없다고 가정하지 않는다.
- 자연어 vec2text 복원이 반드시 필요한 인터페이스라고 고정하지 않는다.
- 모든 경험학습이 schema learning이라는 정의로 가설을 반증 불가능하게 만들지 않는다.
- 코드·unit test·문서 gate를 실제 학습 효용 또는 제품 E2E 성공으로 승격하지 않는다.
- 뇌가 모든 기억의 불변 버전을 보관한다거나 하나의 universal switch가 모든 schema를 고른다고 주장하지 않는다.

## 6. 연구의 성공을 읽는 법

깊게 풀었던 답을 그대로 재출력하는 것이 아니라, 새 사례에서 공통 관계를 재사용해야 한다. 불일치 상황에는 그 편향을 적절히 제한해야 한다. insight는 loop 수가 많다는 뜻이 아니라 **새 표현·관계·적용 조건의 형성과 이후 전이**로 운영적으로 정의한다.
