- 읽어서 확인한 내용(LITERATURE, 논문 귀속):
  * 구조: schema를 syntactic free multicategory Sch_syn, implementation functor(Grothendieck 구성으로 Sch_impl), Giry monad의 Kleisli 범주에 대한 semantic 범주 Sch_sem 세 층으로 나누고, 그 위에 workflow(duoidal), Mind(관측·결정·잠재 변수, 내부 예측 모델, memory와 cognitive module), Body, ArchCat, World 층을 둔다(초록, §1).
  * schema 객체의 정의(정의 3.1.1): 객체는 도메인·코도메인 쌍으로 정해지는 schema 타입 {S_P(지각), S_M(운동), S_G(목표·평가), S_Pred(예측), S_Abs(추상)}이다. 예측 schema는 관측 O·결정 D·잠재 H·목표 G의 곱 사이의 사상이다. 저자는 abstract schema의 형식화가 아직 진행 중이라고 쓴다. 즉 schema는 타입(무엇을 무엇으로 사상하는가)으로 정의되며, 여러 경험에 걸친 재사용이나 새 사례의 학습 비용 감소라는 기능적 정의가 아니다.
  * 연산자(정의 3.1.2, 3.1.10, 3.1.11): 기본 연산자 O = {null, Comb(직렬·병렬), Encap, Ref, Ctx, Add, Del}. Add는 schema 집합에 새 schema를 더하고 Del은 집합에서 schema를 제거하며(Del: "syntactic elimination or deactivation of a schema within a family"), Del은 중립·멱등·교환 법칙을 만족하는 집합 연산이다. Ref는 schema를 더 작거나 구체적인 둘로 분해하고, Encap은 두 schema에서 추상 schema를 만들며, Ctx는 다른 schema의 조건 충족 여부로 활성화를 조절한다. 구현 층(정의 3.2.4)에는 syntactic schema를 고정한 채 표현 언어·파라미터만 바꾸는 vertical 연산자 Transform·Update가 있고, 구조 연산자는 horizontal 사상으로 올라간다(Remark 3.3).
  * 설계 원칙(§2.1): knowledge와 learning을 modular·hierarchical·factorized하게 관리해 catastrophic forgetting/interference를 막고, "changes in one schema should only affect, at most, with minimal changes in other schemas"라고 선언한다. §2.5는 memory를 수동적이지만 구조화된 기질로, cognitive module을 memory를 읽고 쓰는 능동 처리로 엄격히 나눈다. §2.6은 monolithic 모델의 scaling만으로는 일반지능에 이를 수 없다는 입장을 밝힌다(입장 진술이며 실험 없음).
  * memory subsystem은 (Data_M, Ops_M, write_M, read_M)로 정의되고 Ops_M의 예시에 store, retrieve, aggregate, forget이 있다(Definition 5.2.1).
  * 저자 자체 평가: "The primary contribution of this paper is not a closed or finalized formal system, but a coherent structural program"(§1). §7 전체가 진행 중 항목이다(7.1: add·delete operator와 맞는 schema 집합의 정의, abstract schema 정의, 기본 연산자 성질의 증명, Implementation category 논의 등). §7.5의 서술은 "guiding principles and proof objectives rather than fully closed theorems"이고 부록 A·B의 수렴 결과는 "exploratory"로 표시된다. §7.6 "Agents and LLMs workflows"는 항목 제목만 있고, §8 Conclusion은 작성 전 문구 상태이며, §8.1에는 LLM agent의 위치에 관한 메모만 있다.
  * 신경망 학습 실험·벤치마크·코드는 제시되지 않는다.

- 읽어서 확인한 내용(LITERATURE, 논문 귀속):
  * 방법: 사전학습 가중치는 고정하고 MLP gate projection 가중치마다 trainable logit 하나를 둔다. 학습 중에는 sigmoid(alpha*G) 연속 mask를 쓰고 alpha를 선형으로 키워 hard threshold로 만든다. 배포 시 logit이 양수인 가중치는 유지, 음수이면 0이다. 새 값은 쓰지 않으므로 adapter는 가중치당 1비트다. 초기화는 Wanda 점수에 기반한다. 희소도 목표는 없다.
  * 결과: GRPO·SFT·on-policy distillation에서 "가장 큰 backbone"에서 full fine-tuning(FFT)과 같은 정확도다(예: Llama8B GSM8K 83.55 대 FFT 83.24, Qwen7B SimpleRL-Zoo 52.32 대 51.89, Qwen3-30B-A3B 58.54 대 58.43). 작은 모델에서는 FFT의 90–99%(Llama1B GSM8K 54.44 대 60.50). 모든 GRPO 실행에서 삭제 비율이 0.05% 미만. mask는 zstd 압축 후 Llama1B 1.0 MB, Llama8B 8.4 MB(FFT 30,633 MB).
  * 보존: Llama 1B/3B/8B의 단일 GRPO(GSM8K) 실행에서 base 정책 대비 forward KL이 0.05 이하이고 6개 prior-task(HellaSwag, MMLU, TruthfulQA, WinoGrande, IFEval, HumanEval) 평균 정확도가 base의 1점 이내였다. FFT는 1.3–3.1점, LoRA·MTH는 최대 5.4점 아래였다. forward KL이 망각을 예측한다는 것은 선행연구(Shenfeld 외 2026b)의 결과를 인용한 것이고, 삭제가 forward KL을 낮게 유지해 망각이 적다는 설명은 저자의 가설(hypothesize)이다.
  * 한계(저자 기술): "Because Deletion Tuning forgets little, a natural next test is continual learning over a sequence of tasks." 즉 과제를 순차로 배우는 지속학습은 시험되지 않았다. 학습 중에는 가중치마다 logit을 두므로 LoRA보다 메모리를 더 쓴다. 과제별 mask의 합집합으로 skill을 합치는 방안은 미시험 아이디어로만 적혀 있다.
  * 하드웨어: H200 GPU(1B~3B는 1장, 큰 모델은 FSDP 다중 GPU), SFT·사후 분석은 L40S.

- 읽어서 확인한 내용(LITERATURE, 논문 귀속):
  * 방법: 발신 모델과 수신 모델을 모두 고정하고, 약 300M 파라미터 transformer mapper(블록 B=7~9, 폭 1024)를 쌍마다 따로 학습한다. mapper는 발신 모델의 KV cache를 cross-attention으로 읽어 수신 모델 layer group별 KV cache를 예측한다. 목적함수는 수신 모델 native cache에 대한 RMS 정규화 MSE와, 고정 수신 모델을 통과한 next-token NLL이다. 학습 데이터는 영어 텍스트 44M unique token(PG-19·WikiText-103·여러 QA 학습 분할)이고 초록은 "<50M tokens and <1 GPU-day"라고 쓴다.
  * 평가: 6개 모델 계열(Qwen 3, Llama 3, Gemma 2/3, Ministral 3, Granite 3, SmolLM3, 3B~32B)의 10개 계열 간 쌍, 17개 벤치마크에서 수신 모델 자체 점수 대비 평균 보존율이 소형 발신->대형 수신에서 90% 이상(표 2). 초록의 "평균 40% 높은 정확도, 평균 4배 빠른 wall-clock"은 KV 압축(AM)과 결합한 SwaT와 텍스트 요약(T2T)을 3개 모델 쌍·5개 예산·7개 데이터셋에서 비교한 값이다(표 3의 개별 점수는 +14.9~+19.0점).
  * 한계(저자 기술): 발신-수신 쌍마다 mapper가 필요하다(n개 계열이면 n(n-1)개). 반복 전달·여러 메시지 집계는 다루지 않고 한 번의 handoff만 평가한다. KV cache는 텍스트만큼 조합되지 않고 열화될 수 있다. 윤리 절: 현재 구현은 발신자의 텍스트가 있어야 하며, cache에 텍스트에 없는 정보가 담길 수 있어 감사 가능성·안전성은 향후 과제다.
  * 동기 부여로 Platonic Representation Hypothesis를 인용한다(P5와 같은 가설 계열).
- 중복 여부 (280dc9a): 없음. 이름이 비슷한 별도 연구가 있다: arXiv 2609.32259 "Prefill-Free Cross-Family KV Cache Transfer for Heterogeneous Multi-Agent LLMs"(alphaXiv 검색 목록 기준, 미검증). 같은 논문으로 혼동하지 않는다.
- 설계 연결: TI-05, TI-06. H4 text interface(docs/05 §10, docs/12 §1)와 migration adapter 후보(docs/07 §6).
