## Symbolic/discrete/hybrid

Schema Networks [S15]는 명시적 생성·인과 관계를 사용한 transfer의 기초다. Hidden Schema Networks [S13]는 neural encoder/decoder를 쓰지만 중심 schema는 discrete graph/path다. Schema-learning and rebinding [S14]는 CSCG의 전이 구조와 새 token 연결을 다룬다.

S-HAI [S10]는 상위 transition과 하위 공간 states의 grounding을 학습한다. 2026-10-26 v3로 보고된 구현은 **하나의 schema와 여러 grounding**이었다. 새 schema 생성·수정·경쟁·조합까지 구현한 것으로 읽지 않는다.

LCNet [S04]는 shared neural weights와 context vector, discrete latent-cause inference를 결합한다. 공유 구조와 상황별 차이/간섭을 관리하는 비교 대상으로 중요하지만 fully continuous schema 체계라고 단순화하지 않는다.

Schema for ICL [S16]은 명시적 reasoning template를 prompt로 사용하는 경로다. 내부 neural schema의 지속학습과 다른 축으로 평가한다.

## 실제 뇌의 표현 관련 논의

N26 이야기 실험: 서로 다른 내용에서도 공통 event/script 구조의 fMRI pattern.
N27 인간 single-unit 연구: 관측 변수와 latent context의 abstract geometry. pseudo-population 해석 한계.
N28 원숭이 PMd: decision schema와 stimulus 변화의 near-orthogonal organization. 모든 schema의 직교성 아님.
N29 subiculum–OFC: 단일 hippocampus→cortex 직렬 그림을 경계할 현상으로 언급됐지만 안정된 논문 식별자는 미확보.
N30/N31 replay와 conceptual recombination: 정확한 원문 연결을 추가 확보할 항목으로 보존.

Schema spectrum [S17]은 분산된 지식의 추상화 연속선을 제안한 Perspective다. 새로운 실험 사실로 소개하지 않는다.

## 현재 모델로의 해석

안정적인 구조와 빠른 새 binding을 분리하되, 구조의 수정/성장도 가능해야 한다. Schema가 표현되는 곳이 vector 하나인지 dynamics인지 parameter subspace인지 미리 고정하지 않는다. 목표는 저장량보다 후속 학습·전이·계산 절감이다.
