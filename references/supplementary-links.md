# 추가 공식 설명과 이관 경계

이 링크들은 대화에서 논문 설명과 구현 배경으로 사용됐다. 논문 원문과 별도의 설명 자료이며 같은 연구를 중복 독립 근거로 세지 않는다.

- [Google Research — Sleep framework](https://research.google/blog/the-sleep-framework-a-new-way-for-llms-to-retain-knowledge-in-continual-learning/): 수치 weights와 기억 구조의 학습, 개발 코드 진화의 구분.
- [Sakana AI — Darwin Godel Machine](https://sakana.ai/dgm/): 후보 계보와 평가 우회 사례에 대한 설명.
- [KAIST 기억 선택 원문](https://doi.org/10.1038/s41593-026-02280-6): 사용자 공유 기사 내용과 실제 원논문 범위를 구분하는 기준.
- [Titan-Llama fork README pin](https://github.com/sarahpannn/titans-pytorch/blob/c60b4efaa3a3c6df4deebd57cbccf75947b87cad/README.md): unofficial upstream과 저자 fork의 Titan-Llama 추가를 구별.

공개 source의 존재는 로컬 실행·재현 성공이 아니다. 외부 프로젝트를 vendoring할 때는 라이선스와 정확한 revision을 별도 확인한다. 이 저장소는 third-party source를 복사하여 라이선스를 새로 부여하지 않는다.
